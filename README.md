# Tailwind Modern Dashboard

A modern, clean, and fully responsive dashboard built using **HTML5** and **Tailwind CSS**. The project focuses on semantic HTML, responsive layouts, and a professional dashboard UI.

## ✨ Features
- 📱 Fully responsive design
- 🏷️ Semantic HTML5 structure
- 📊 Dashboard statistics and overview
- 📋 Recent customer orders table
- 💰 Order amount and status display
- 📈 Monthly performance overview
- 📊 Progress bars for Sales, Orders, Customers, and Products
- 📱 Responsive sidebar navigation
- 🎨 Clean and modern UI
- 🧹 Clean and organized code
- ⚡ JavaScript-powered interactive functionality

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript**
* **Lucide Icons**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Muhammad-Arshiyan/tailwind-dashboard.git
```

### 2. Open the project

```bash
cd tailwind-dashboard
```

### 3. Run the project

Open `index.html` directly in your browser, or use **VS Code Live Server**.
